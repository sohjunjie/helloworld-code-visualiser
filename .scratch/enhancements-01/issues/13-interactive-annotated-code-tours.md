# 13 — Interactive Annotated Code Tours

**What to build:** Build an interactive guided code tour creation and player system that allows developers to record or play step-by-step walkthroughs through key codebase paths, featuring animated camera transitions across Cytoscape nodes, custom annotations, auto-generated entry-point tours, and JSON tour import/export.

**Blocked by:** 03 — SVG Diagram Export & Advanced Graph Filtering

**Status:** ready-for-agent

- [ ] Tour Player allows stepping through sequence checkpoints with animated pan-and-zoom transitions focusing on each target node in the graph.
- [ ] Sidebar presents step descriptions, code snippet references, and architecture commentary for each checkpoint.
- [ ] Tour Builder mode allows developers to record custom tours by selecting nodes and entering step notes.
- [ ] Tours can be exported as standalone JSON files and imported into any visualization session.
- [ ] An auto-generated "Quick Tour" analyzes graph entry points and traces critical pathways to leaf nodes automatically.
